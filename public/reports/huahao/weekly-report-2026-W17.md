### 2. 博客矩阵发布（canvas 关键词集群）

- 本周完成围绕 **canvas bag** 关键词集群的首批文章规划与发布，与前两周的 non-woven bag、woven bag 系列共同构建关键词覆盖矩阵。
- 文章选题方向包括：
  - `what is a canvas bag`（科普向，捕获信息型搜索）
  - `canvas bag vs other bags`（对比向，辅助购买决策）
  - `custom canvas bags wholesale`（商业应用向，转化潜力高）
- 所有文章完成 On-Page SEO 基础配置，内链连接至产品页及 Solution 页。
- 关键词矩阵（non-woven / woven / canvas）已形成初步规模，后续继续扩展 long-tail 关键词覆盖，节奏维持每周 2～3 篇。

### 3. Schema 数据补充

- 本周启动站点 Schema 结构化数据的系统性补充工作，目标覆盖以下类型：
  - **FAQ Schema：** 适用于博客文章及产品问答模块，提升搜索结果富摘要展示概率。
  - **BreadcrumbList Schema：** 为所有内页配置面包屑标记，优化搜索结果路径显示。
  - **Product Schema：** 为产品页补充价格、评分、库存等结构化字段，支持 Google Shopping 展示。
  - **Article Schema：** 为博客文章配置发布时间、作者、分类等标记，提升内容权威性信号。
- **进度：** 配置规范已确定，正在分类型逐步上线，FAQ 与 Breadcrumb 优先推进。

### 4. 案例素材整理

- 本周完成案例素材整理工作：
  - 梳理并归档竞对站点客户案例参考样本
  - 整理现有产品图片资源，评估可用于案例配图的素材清单
  - 与内部沟通确认真实客户使用场景素材获取计划
- **进度：** 素材池初步建立，下周进入正式写作阶段，计划产出 2～3 篇客户案例。

### 5. Robots 协议优化 & 异常 Page 排查

- 发现 Google Search Console 中"已发现但未收录"数量异常增长（当前 3,658 页），初步判断存在以下问题：
  - URL 参数页面（如 `?color=`、`?size=` 等筛选参数）被大量抓取，产生重复/低质内容页。
  - 部分无实质内容的分页、归档页、标签页被列入发现队列。
- **优化方向：**
  - 在 `robots.txt` 中屏蔽无需收录的参数页、归档页路径。
  - 配置 Google Search Console URL 参数处理规则（如将筛选参数标记为"不影响页面内容"）。
  - 对已发现页面进行人工抽查，确认是否存在误收录或重复收录情况。
- **进度：** 问题已识别，完成配置，待验证效果。
