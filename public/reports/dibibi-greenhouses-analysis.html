  • 产品线：铝合金温室大棚（核心）、户外储藏棚、花园配件、智能IoT套件、婴儿产品、家用消毒产品
  • 市场定位：B2C（家庭园艺爱好者）+ B2B（批发商、经销商、OEM/ODM客户）
  • 全球化程度：已在超过20个国家安装交付，参展 GLEE（英国）、SPOGA+GAFA（德国）、GARDENIA（波兰）等国际展会

2.2 内容质量问题

问题一：产品描述高度雷同

几乎每个产品系列描述均使用相同模板语言：

"P1/P2/P3 series uses a higher standard of manufacturing process, quality and performance…"

没有差异化的产品卖点阐述，用户无法快速区分各系列的核心区别，严重影响购买决策。

问题二：品牌叙事混乱

  • 网站声称品牌"originated from France"，但联系页地址全为中国（金华、杭州）
  • 品牌名下还包含婴儿产品线（DouxBebe）、HCIO消毒液研发，与花园温室定位割裂
  • "It's always day 1 at DiBiBi"的 slogan 使用频率过高但语境突兀

问题三：内容深度不足

博客/Ideas 页虽有文章，但存在以下问题：

  • 文章结构缺乏权威感（无数据引用、无实验案例、无用户故事）
  • 内容与产品页之间内链稀少，流量无法有效引流至转化页
  • 行业内容与公司新闻混放（公司年会、员工活动等内容与产品指南并列）

问题四：常见问题页质量参差不齐

FAQ 页包含部分高质量内容（如温室选址、雪负荷、风阻说明），但：

  • 部分答案未与具体产品型号绑定，缺乏商业引导
  • 缺少安装教程类内容（如视频、步骤图）
  • 未覆盖B2B买家最关心的MOQ、交期、定制流程问题

2.3 优质内容亮点

  • Greenhouse Dimensions 101：结构化的专业指南，覆盖小/中/大规格对比，面向 B2B 和 B2C 的双重场景，是目前最强的 SEO 内容
  • The Ultimate Guide to Greenhouse Types：涵盖 lean-to、A-frame、Gothic arch、Victorian 等多类型，内容全面
  • 经销商页面：明确列出合作条件和产品范围，是 B2B 漏斗的重要入口

3.2 技术 SEO 问题（推断）

基于内容结构和页面表现的推断性分析：

  • Title / Meta 同质化：多个产品页 Title 使用相似模板，关键词竞争力弱
  • 内链不足：博客文章与对应产品页之间缺乏有效内链，权重无法传递
  • 页面内容薄：多个产品子页内容极少（仅为列表 + 重复描述），可能触发 thin content 惩罚
  • 结构化数据缺失：产品页缺乏 Schema.org 产品标记（Price、Review、Availability），无法展示富摘要
  • 图片 ALT 优化不足：产品图片缺乏包含关键词的描述性 ALT 文本
  • URL 结构：部分页面 URL（如 /rd/）缺乏关键词，SEO 友好度低

3.3 内容 SEO 机会缺口

4.2 技术问题清单

高优先级

  • Cookie 弹窗合规性：当前使用简单文字提示（"This website uses cookies..."），不符合 GDPR/UK-PECR 要求（缺乏分类同意、拒绝选项）
  • 页面加载速度：产品图片密集，需验证是否有 WebP 格式输出和懒加载
  • Core Web Vitals：LCP / CLS 需专项测试，温室产品图尺寸大概率影响 LCP

中优先级

  • 移动端适配：导航菜单层级多（多语言 + 多产品线），移动端体验待优化
  • HTTPS：需确认全站 HTTPS 正确配置
  • 404 / 重定向：产品页迭代后旧链接需检查
  • Sitemap & Robots.txt：需确认结构正确，防止关键页面被屏蔽

低优先级

  • 结构化数据：添加 Organization、Product、FAQ、BreadcrumbList Schema
  • Hreflang 标签：双语站需正确配置语言标签，防止搜索引擎混淆

五、转化路径分析

5.1 B2C 用户转化路径现状

七、优化方案

7.1 内容优化（短期：1-3个月）

优先级 P0

  1. 重写产品描述：每个系列单独撰写差异化的 300-500 词产品介绍，明确各系列的核心卖点对比（P1 vs P2 vs P3 vs U系列有何本质不同？）
  2. 建立产品对比表：创建统一的参数对比页，帮助用户快速选型（尺寸/材质/价格区间/适用场景）
  3. 清理公司内部新闻：将年会、销售会议等内部新闻从博客移至独立新闻专区，保持主博客聚焦园艺与产品内容

优先级 P1

  1. 强化 B2B 内容：专门创建 OEM/ODM 服务页（含流程、认证、起订量、交期等信息）
  2. 添加案例研究：创建 3-5 篇客户案例（零售商采购案例、个人用户搭建案例）
  3. 产品规格 PDF 下载：每个系列提供可下载的技术规格书

7.2 SEO 优化（中期：3-6个月）

  1. 关键词分群：将目标词按意图分为信息型、导航型、商业型、交易型四类，分别对应不同内容形态
  2. 内链系统：建立从博客文章到产品页的系统性内链，每篇博客至少关联2个产品页
  3. Title/Meta 重写：每个页面撰写唯一的、包含目标关键词的 Title（60字符内）和 Meta Description（160字符内）
  4. 添加 Schema：Product、FAQ、Organization、BreadcrumbList
  5. 地区化内容：针对英国、德国、澳大利亚等主要市场创建本地化园艺指南

7.3 技术优化（中期：2-4个月）

  1. Cookie 合规：接入 Cookiebot 或 Complianz 实现 GDPR 合规弹窗
  2. 图片优化：全站图片转 WebP，启用懒加载，为产品主图添加含关键词的 ALT 文本
  3. 页面速度：目标 LCP < 2.5s，FID < 100ms，CLS < 0.1
  4. Hreflang：正确配置中英文双语 Hreflang 标签

7.4 转化优化（短期：1-2个月）

  1. 产品页增加 "Get Quote" 浮动按钮
  2. 首页增加选型工具（几个简单问题引导用户找到适合的产品）
  3. 在博客文章中嵌入产品推荐卡片
  4. 经销商页面增加合作流程图和资质展示
