Obsidian Git 将 Git 操作带进 Obsidian，适合为笔记保存提交历史，并通过远程仓库维护副本。它让笔记库的修改有可追踪记录，便于查看哪些文件发生变化，以及必要时比较或恢复历史内容。

## 主要用途

- **记录版本历史**：按工作节奏提交修改，保留资料演变过程。
- **连接远程仓库**：在正确配置下推送与拉取内容，维护其他位置的副本。
- **查看文件变化**：了解一次修改涉及哪些笔记，辅助整理和排查。

## 使用场景

维护技术知识库时，可以在完成一轮整理后提交，并同步到私人仓库。Git 需要处理冲突与凭据，移动端能力也应核对；它并非无需管理的实时同步。
