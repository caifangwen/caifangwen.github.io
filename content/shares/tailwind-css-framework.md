Tailwind CSS 通过实用类组合样式，把布局、间距、颜色和响应式规则直接应用到界面中。它适合需要快速迭代页面、同时希望保持视觉约定一致的项目，例如企业官网、产品落地页和应用后台。

## 主要用途

- **快速组织布局**：用统一规则处理间距、网格、排版和不同屏幕尺寸。
- **维护视觉规范**：围绕项目的颜色和尺寸约定，减少页面之间随意变化。
- **配合组件开发**：把常见样式与组件一起维护，方便复用和调整。

## 使用场景

制作营销页面时，可以先确定字体、颜色与内容宽度，再组合不同区块。项目变大后应提取常用组件，避免大量重复样式难以同步修改。

## 相关工具

[Astro](astro.md) 适合内容网站；[Next.js](nextjs.md) 可用于应用开发；[shadcn/ui](shadcn-ui.md) 提供可定制的界面组件，可结合项目样式规范使用。
